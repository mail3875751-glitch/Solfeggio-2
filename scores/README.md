# Соло — курс «Буги-вуги» 2.0, урок 5 (Юлия Шишкина)

Транспозиция авторской пьесы в четыре тональности.

| Тональность | Ноты | Исходник |
|---|---|---|
| C  | [solo-c.pdf](solo-c.pdf)     | авторский оригинал (пересобран) |
| G  | [solo-g.pdf](solo-g.pdf)     | авторский оригинал (пересобран) |
| **F**  | **[solo-f.pdf](solo-f.pdf)**     | **новая транспозиция** |
| **B♭** | **[solo-bes.pdf](solo-bes.pdf)** | **новая транспозиция** |

## Как это сделано

Ноты сняты прямо из авторских PDF (`Соло в C` и `Соло в G`): из потока
страницы разобраны координаты каждой нотной головки, знака альтерации, паузы
и тактовой черты, и по положению относительно линеек восстановлены точные
высоты. Две авторские версии сверены между собой — они совпали нота в ноту,
что подтверждает правильность съёма.

Результат записан в LilyPond (`solo.ily`) в до мажоре; остальные тональности
получаются через `\transpose`.

## Выбор регистра

Правая рука транспонируется строго, целиком:

* **F** — на чистую квинту вниз от C (это ровно на тон ниже авторской версии G);
* **B♭** — на большую секунду вниз от C.

Левая рука (буги-бас: основной тон + квинта / основной тон + секста) в каждой
тональности выписана отдельно, чтобы бас оставался в удобной октаве. Это то же,
что сделал автор: в оригиналах основные тоны баса всегда лежат в малой октаве
(C: C2–F2–G2, G: G2–C2–D2), а не переносятся механически.

| | правая рука | левая рука (I / IV / V) |
|---|---|---|
| C (ориг.)  | C4–C6   | C2–E3 · C2 / F2 / G2 |
| G (ориг.)  | G3–G5   | C2–E3 · G2 / C2 / D2 |
| F          | F3–F5   | F2–A3 · F2 / B♭2 / C3 |
| B♭         | B♭3–B♭5 | E♭2–G3 · B♭2 / E♭2 / F2 |

Аппликатура, лиги, форшлаги, паузы и «Swing» сохранены — интервалы в аккордах
при транспозиции не меняются, поэтому пальцы те же.

## Проверка

Из собранных партитур выгружен MIDI и сверен с высотами, независимо
извлечёнными из авторских PDF:

* версия C — совпадение 196 из 196 нотных событий;
* версия G — совпадение 196 из 196 нотных событий
  (единственное расхождение в обоих случаях — два лигованных аккорда в тактах
  5 и 6, которые в MIDI звучат одной нотой).

Значит, и снятие, и механизм транспозиции воспроизводят оригинал точно.
Для F и B♭ дополнительно проверено, что правая рука — строгая транспозиция
партии C на −7 и −2 полутона соответственно.

## Сборка

```sh
lilypond -o solo-f solo-f.ly       # и так же для solo-c / solo-g / solo-bes
```

Файлы:

* `solo.ily` — нотный материал и партии левой руки для всех тональностей;
* `layout.ily` — формат страницы, размер нотоносца, заголовочный шрифт;
* `solo-*.ly` — по файлу на тональность.
