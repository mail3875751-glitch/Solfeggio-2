# Shuffle backing tracks

Один и тот же минус в разных темпах. Барабаны, 4/4, шаффл (восьмые триольные:
добавочные удары на третьей триоли 3-й и 4-й долей).

| Файл | Темп | Структура | Длительность |
|---|---|---|---|
| `Shuffle_100bpm.mp3` | 100 | оригинал, 3 квадрата | 91.6 с |
| `Shuffle_100bpm_2sq.mp3` | 100 | 2 квадрата | 62.8 с |
| `Shuffle_120bpm_2sq.mp3` | 120 | 2 квадрата | 52.3 с |
| `Shuffle_140bpm_2sq.mp3` | 140 | 2 квадрата | 44.8 с |
| `Shuffle_120bpm_3sq.mp3` | 120 | 3 квадрата | 76.3 с |
| `Shuffle_140bpm_3sq.mp3` | 140 | 3 квадрата | 65.4 с |

## Структура

- **Такты 1–2 — отсчёт.** Метроном: такт 1 — доли 1 и 3, такт 2 — доли 1, 2, 3, 4.
- **Квадраты по 12 тактов**, в 12-м такте каждого — сбивка.
- Заключительный удар на первой доле следующего такта + затухание.

Оригинал содержит три одинаковых квадрата (такты 3–14, 15–26, 27–38); версии
`_2sq` обрезаны до двух — такты 1–26 плюс финальный удар, склейка 6 мс
equal-power прямо перед ударом, в тихом месте.

## Сборка

`./build_tracks.sh` — пересобирает `_2sq` из оригинала. Нужен ffmpeg с
librubberband.

Порядок: снятие задержки mp3-кодера (1088 сэмплов) → обрезка → растяжение по
времени без изменения высоты тона (`rubberband`, перкуссионный детектор, crisp
transients, короткое окно, фазово-связанное стерео) → нормализация до −0.1 dBFS
→ 320 kbps / 44.1 kHz.

## Проверено

- Длительность 26 тактов совпадает с идеальной: 62.4000 / 52.0000 / 44.5714 с —
  значит средний темп ровно 100, 120 и 140.
- Второй квадрат совпадает с первым с точностью 0–1.5 мс.
- Клиппинга нет ни в одном файле.
