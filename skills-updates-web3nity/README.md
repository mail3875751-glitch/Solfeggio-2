# Обновления скиллов по итогам разбора пака Web3nity (2026-07-20)

Перенос лучших идей из `presentation-skills-public-pack` (Web3nity) в экосистему
скиллов пользователя. Пак предварительно проверен на безопасность (только .md/.json,
без исполняемого кода, инъекций и внешних URL) и разобран посравнительно со стеком
pptx-strict / pptx-critic / токен-слой.

Выход `presentation-blueprint.md` — вход для pptx-strict; статусы «нужно проверить» → fact-checker-pro |

## Установка в источник правды (репозиторий claude-skills)

1. `pres-blueprint/` — скопировать папку целиком в корень скиллов.
2. `pptx-strict/SKILL.md` — заменить (полная копия v1.5).
3. `schema.md` — заменить **во всех трёх местах** (копии обязаны быть побайтно
   одинаковыми): `pptx-strict/references/tokens/`, `doc-style/references/tokens/`,
   `xlsx-style/references/tokens/`.
4. `evals/evals.json` — положить в соответствующие скиллы.

Сознательно НЕ перенесено из пака: builder (слабее pptx-strict), identity-dna
(закрыт токен-слоем), самопроверка внутри производителя (архитектурно уступает
паре strict/critic + Critic-gate).
