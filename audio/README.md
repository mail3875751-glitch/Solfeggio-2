# Shuffle backing tracks

Три версии одного и того же минуса — идентичная структура, разный темп.

| Файл | Темп | Длительность |
|---|---|---|
| `Shuffle_100bpm.mp3` | 100 BPM | 91.6 с (исходник) |
| `Shuffle_120bpm.mp3` | 120 BPM | 76.3 с |
| `Shuffle_140bpm.mp3` | 140 BPM | 65.4 с |

## Структура (одна и та же во всех трёх)

- **Такты 1–2 — отсчёт.** Метроном-клик: такт 1 — доли 1 и 3, такт 2 — доли 1, 2, 3, 4.
- **Такты 3–38 — грув.** Шаффл-барабаны, 4/4, три одинаковых 12-тактовых квадрата
  (такты 3–14, 15–26, 27–38), в конце каждого — сбивка в 12-м такте.
- Заключительный удар на первой доле такта 39 + затухание.

Восьмые триольные (shuffle): дополнительные удары приходятся на третью триоль
долей 3 и 4.

## Как сделаны 120 и 140

Исходник — экспорт из Logic Pro, 160 kbps. Из него убрана задержка mp3-кодера
(1088 сэмплов), затем растяжение по времени без изменения высоты тона
(`rubberband`, `transients=crisp:detector=percussive:window=short:phase=independent:channels=together`),
коэффициенты 1.2 и 1.4. Пик выровнен по исходнику, экспорт 320 kbps / 44.1 kHz.

Сетка проверена: длительность 38 тактов совпадает с идеальной до 0.1 мс
(76.0000 с при 120 и 65.1429 с при 140), расхождение петель — в пределах 1.5 мс,
клиппинга нет.
