# Shuffle backing tracks

Один и тот же минус в разных темпах и разной длины. Барабаны, 4/4, шаффл
(восьмые триольные: добавочные удары на третьей триоли 3-й и 4-й долей).

| Файл | Темп | Квадратов | Длительность |
|---|---|---|---|
| `Shuffle_100bpm.mp3` | 100 | 3 (оригинал) | 91.6 с |
| `Shuffle_100bpm_2sq.mp3` | 100 | 2 | 62.8 с |
| `Shuffle_120bpm_2sq.mp3` | 120 | 2 | 52.3 с |
| `Shuffle_140bpm_2sq.mp3` | 140 | 2 | 44.8 с |
| `Shuffle_120bpm_3sq.mp3` | 120 | 3 | 76.3 с |
| `Shuffle_140bpm_3sq.mp3` | 140 | 3 | 65.4 с |
| `Shuffle_120bpm_10sq.mp3` | 120 | 10 | 244.3 с |

## Структура

- **Такты 1–2 — отсчёт.** Метроном: такт 1 — доли 1 и 3, такт 2 — доли 1, 2, 3, 4.
- **Квадраты по 12 тактов**, в 12-м такте каждого — сбивка.
- Заключительный удар на первой доле следующего такта + затухание.

Оригинал содержит три одинаковых квадрата (такты 3–14, 15–26, 27–38). Сборки
берут эти три записи по кругу, поэтому подряд один и тот же кусок не идёт.

## Сборка

```
./make_minus.py --bpm 120 --squares 10     # любая комбинация
./build_tracks.sh                          # весь комплект разом
```

Порядок: снятие задержки mp3-кодера (1088 сэмплов) → раскладка блоков со
склейкой 6 мс equal-power (стык всегда в тихом месте перед сильной долей, сама
доля не тронута) → растяжение по времени без изменения высоты тона
(`rubberband`, перкуссионный детектор, crisp transients, короткое окно,
фазово-связанное стерео) → нормализация до −0.1 dBFS → 320 kbps / 44.1 kHz.

## Проверено

- Длительность совпадает с идеальной сеткой: 26 тактов = 62.4000 / 52.0000 /
  44.5714 с, 122 такта при 120 BPM = 244.0000 с. Значит средний темп ровно 100,
  120 и 140.
- Квадраты внутри файла совпадают между собой с точностью 0–1.5 мс.
- На стыках нет ни выброса, ни провала уровня; клиппинга нет ни в одном файле.
