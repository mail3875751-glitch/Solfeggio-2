# image-prompt · модуль «Портрет по референсу»

Готовый к вставке раздел для скилла `image-prompt`: [portrait-by-reference.md](portrait-by-reference.md).

## Почему модулем, а не правкой скилла

Скилл лежит в синхронизированной копии `~/.claude/skills/synced/image-prompt/SKILL.md`, и её футер говорит прямо:

> `здесь не править: истина в C:\skill-house, правки вернуть Клоду`

Копия ещё и живёт в эфемерном контейнере — правка в ней исчезнет вместе с сессией. Поэтому раздел собран отдельным файлом: его переносят в мастер `C:\skill-house\image-prompt\SKILL.md`.

## Что вносить в мастер-копию

**1.** Вставить содержимое `portrait-by-reference.md` (без HTML-комментария в шапке) целиком — **после** раздела `## Edit Prompt Protocol` и **перед** `## Prompt Structure (Generation Mode)`.

**2.** В разделе `## Two Modes: Generation vs Edit` переименовать заголовок в `## Three Modes: Generation, Edit, Portrait-by-Reference` и добавить третий абзац:

```
**Portrait-by-reference mode** — placing a specific real person into a composition
taken from someone else's photo. Use the Портрет по референсу section. Triggered when
the user uploads their own photos together with a reference image, or asks for
"such a photo, but with me".
```

**3.** В `description` во фронтматтере дописать в конец списка триггеров:

```
'портрет по референсу', 'хочу такое же фото но со мной', 'сделай меня в этом образе',
'фото как на этой картинке', 'подставь меня', 'портрет по своим фото'
```

**4.** Во фронтматтере поднять `metadata.version` до `"1.1"`.

**5.** В `## Pre-Generation Checklist` добавить пункт:

```
- [ ] **Реальный человек в кадре:** применён ли блок FIDELITY LOCK против идеализации
      тела, возраста и пропорций? (Identity Anchoring закрывает только лицо.)
```

## Что именно даёт модуль

| Блок | Какой отказ закрывает |
|---|---|
| Запрет подавать референс картинкой | конфликт двух визуальных доноров: лицо заказчика на чужой фигуре |
| Identity Card | дрейф сходства на длинных промтах |
| Разделение Identity / Scene | конфликт слоёв: «улыбается» против «нейтральное лицо» |
| `FIDELITY LOCK` | регрессия к эстетическому среднему по телу, возрасту и пропорциям |
| Хвостовой повтор задачи | размывание инструкции в середине длинного промта |
| Чек-лист брака | отбор, которого в скилле не было вовсе |
| Session / wardrobe lock | серия из N кадров как одна съёмка, а не десять разных людей |

## Источник

Механика двухслойного промта и приём «не отдавать референс изображением» — из туториала «Как сделать портрет с помощью ИИ — чтобы действительно было похоже» (habr.com/ru/articles/1072142/). Формулировки промтов переписаны, объяснения причин, чек-лист брака, консистентность серии, границы и этика — добавлены.
