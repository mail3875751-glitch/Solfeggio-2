# Буги-вуги Ганон

Генератор оригинального сборника упражнений на технику буги-вуги
и барелхаус-фортепиано. 17 упражнений с аппликатурой, каждое —
модель в до мажоре плюс секвенция по квинтовому кругу через все
двенадцать тональностей.

Материал оригинальный: существующие сборники (Alfassy, Deneff и др.)
не воспроизводятся ни нотным текстом, ни аппликатурой.

## Что получается

- `out/Boogie-Woogie-Hanon.pdf` — сборник, 20 страниц A4
- `out/musicxml/ex*.musicxml` — исходные ноты по упражнениям;
  открываются в MuseScore, Sibelius, Finale, Dorico

## Структура сборника

| Часть | Упражнения | Содержание |
|---|---|---|
| I | №1–8 | левая рука: шагающий бас, октавы, ломаная октава, шаффл, децимы, тресильо |
| II | №9–14 | правая рука: качание, терции, сексты, форшлаги, повторяющиеся ноты, октавы |
| III | №15–16 | координация: три против восьми, синкопа на ровном басу |
| IV | №17 | блюзовый квадрат |

## Сборка

```bash
pip install verovio music21 cairosvg reportlab pypdf
python3 build.py
```

Внешние сервисы и LilyPond не нужны — гравировка идёт через verovio.

## Устройство

- `content.py` — весь музыкальный материал и тексты. Фигуры заданы
  ступенями лада относительно тоники, поэтому переносятся в любую
  тональность без потери правописания знаков.
- `build.py` — сборка: music21 → MusicXML → verovio → SVG → PDF,
  плюс вёрстка страниц на reportlab и склейка через pypdf.

Масштаб гравировки подбирается автоматически: verovio рендерится
дважды — первый прогон измеряет высоту нотного блока, второй
подбирает ширину виртуальной страницы так, чтобы ноты заполнили
и наборную ширину, и всю высоту, оставшуюся под текстом.

Акколада и разрывы строк дописываются в MusicXML вручную
(`postprocess_xml`): music21 их не выгружает.
