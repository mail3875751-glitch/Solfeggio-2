## Сводка оценок

- **Ревизоры (единогласно):** последовательность 7/10 · полнота 5–6/10 · логика 7/10.
- **Главные находки:** (1) сессия воспроизвела петлю владельца — 15+ артефактов
  при нуле действий в мире; (2) исследование рынка запущено после выбора стратегии
  и работало на подтверждение; (3) диагноз одноисточниковый, метафоры мигрировали
  в статус фактов; (4) у плана нет исполнительного слоя (контролёр, протокол срыва,
  держатель растяжки); (5) упущены: runway цифрой, NDA/конфликт интересов,
  энергия/тело/близкие, конкуренция, «право осознанно остаться».
- **Контролёр полноты:** аудит проверял самоотчёт ассистента; конфиденциальность
  корпуса — критический риск (реакция: репозиторий удаляется, мастер-копия
  переносится локально); тезис «страх — исправный прибор» не проверен никем;
  рецепты аудита сами рискуют стать новым производством.
- **Позиция ассистента:** с аудитом согласен, производственный перекос признаю;
  правила ниже приняты и для ассистента тоже.

## Правила (действуют постоянно)

1. **Заморозка производства:** никаких новых дек, версий, открыток и эталонных
   листов, пока не состоялся Разговор №1 (первый внешний контакт).
2. **Анализ покупается действием:** новый аналитический цикл — только после
   одного действия в мире.
3. **Каждое ключевое число носит статус** — факт / оценка / гипотеза; вести
   реестр допущений.
4. **Протокол срыва:** несданное к сроку — не провал, а материал следующей
   сессии; она начинается с 15-минутной экстракции, а не с нового производства.
5. **Метафоры («санаторий», «петля», «таймер», «окно») — рабочие гипотезы
   08.2026 со сроком пересмотра 01.03.2027**, не приговоры.

## Как продолжить работу локально

1. Мастер-копия — скачанная папка «Новое начало» на вашем компьютере.
2. Открыть в ней Claude Code (десктоп или терминал).
3. Первая фраза новой сессии: «Прочитай "ИНСТРУКЦИЯ ПО ИТОГАМ АУДИТА.md",
   "ПАСПОРТ СЕССИИ 2026-08-08.md" и README — продолжаем. Начни с 30-минутного
   интервью по первому списку инвентаризации».
4. В decisions.md фабл-помощника дописать две строки: правило заморозки
   производства до Разговора №1; правило «анализ покупается действием».
5. Дальше вся работа — локально; облачные сессии — только для задач без
   чувствительной фактуры.
